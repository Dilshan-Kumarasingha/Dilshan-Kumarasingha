<br/>

**Flowspace** — Live async standups over SignalR, one-post-per-day rule enforced server-side. Decision log runs a real state machine (Draft → Open → Decided → Superseded) with voting and threaded comments. Lead/Member permissions enforced at the service layer. Tested with RestSharp, Selenium (POM), Dapper DB checks, and Allure reporting.

**HelpDeskHQ** — A recurring Hangfire job scans open tickets against configurable SLA targets per category × priority, auto-escalating breaches to a Team Lead. Every ticket status change is validated server-side. Tests seed backdated tickets via Dapper and invoke the escalation logic directly — validating time-dependent background rules, not just request/response APIs.

**ShopQA** — Full customer flow (browse → cart → checkout → order history) on a JWT-secured Spring Boot API. QA layer covers Selenium UI (Page Object Model), RestAssured API tests, and JDBC DB validation, wired into a GitHub Actions + Allure CI pipeline.
